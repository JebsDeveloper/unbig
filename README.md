# What is unbig?
This project is a command line interface (CLI) tool that will do exactly as the name suggests, makes things less big. It is planned to incorporate multiple compression algorithms varying in compression size and speed. It will be used by running the unbig command with the arguments of a customizable type and an input and output file. For example `unbig -lz4 input.txt output.lz4` will compress the input.txt file using LZ4 compression into the output.lz4 file. It is planned to support generic file types too like `unbig -lz4 input.txt output.bin`. The `.bin` format is generic, just meaning binary, but it will contain a small metadata header to tell unbig exactly how to decompress it. It is also planned to support an auto type where you can just type `unbig input.txt output.bin` or with the optional `-auto` flag to choose a compression algorithm based on the file size which balances compression and decompression speed, and also the final file size.
